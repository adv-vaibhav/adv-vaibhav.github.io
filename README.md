# Adv. Kumar Vaibhav — Portfolio

A responsive professional portfolio for Adv. Kumar Vaibhav, built with Vite and plain HTML, CSS, and JavaScript. 

## Run locally

Install [pnpm](https://pnpm.io/installation), then run:

```sh
pnpm install
pnpm dev
```

Create a production build with `pnpm build`; preview it with `pnpm preview`.

## Deploy to GitHub Pages

The site deploys automatically to GitHub Pages when changes are pushed to the
`main` branch. The GitHub Actions workflow builds the site and publishes the
`dist` directory.

In the repository settings, go to **Settings → Pages** and set the build and
deployment source to **GitHub Actions**. After the workflow succeeds, the site
is available at <https://adv-vaibhav.github.io>.

## Publish a blog post

Add a `.doc` or `.docx` file to [`upload-here/`](upload-here/) and commit it to
`main`.
